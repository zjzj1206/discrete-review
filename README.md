# 离散数学与结构 (I)

正式路径： https://blog.zjzj.work/discrete/

编辑 `content/*.md`，执行 `python3 build.py` 生成 `dist/`。Python 依赖见 requirements.txt；Node 依赖执行 npm ci 安装。数学渲染复用 ICS 的 KaTeX 构建方案，本地自托管字体，不需要第三方运行时 CDN。

块语法：`:::类型 名称` 开始折叠条目，`|||证明或解释标题` 开始嵌套证明，单独一行 `:::` 结束。`@pdf URL` 在展开时加载原卷。其余正文不折叠。

来源原件保存在上级 sources/，不随本项目公开；仅用户要求发布的两份本地考试扫描与补充题配图进入 assets。外部教材与官方题库通过来源链接访问。

当前正文是课程知识整理；复杂元定理标注证明思路。题目索引与已完成解答分别标记。2026 后续教学范围未公布，不承诺历史范围等于本年度考试范围。
