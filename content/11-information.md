# 11 · 熵、散度与互信息

熵衡量平均不确定性，散度比较分布，互信息衡量观察带来的平均信息。计算时先固定联合分布，再由边缘化和条件化得到所需项。

:::定义 熵、联合熵与条件熵
离散随机变量的熵 $H(X)=-\sum_xp(x)\log_2p(x)$，约定 $0\log0=0$。联合熵对联合分布计算；$H(X\mid Y)=\sum_yp(y)H(X\mid Y=y)$。
|||解释
确定变量熵为零。条件熵是各条件分布熵的平均，不是一个随机量；连续微分熵有不同性质，本章结论默认离散变量与有限信息量。
:::

:::定义 KL 散度与互信息
$D_2(P\Vert Q)=\sum_xP(x)\log_2(P(x)/Q(x))$。若 $P(x)>0,Q(x)=0$ 则为正无穷。$I(X;Y)=D_2(P_{XY}\Vert P_XP_Y)=H(X)+H(Y)-H(X,Y)$。
|||解释
KL 一般不对称，不满足距离的三角不等式。自然对数版本记 $D_e=(\ln2)D_2$，尾界 $e^{-nD_e}$ 等于 $2^{-nD_2}$。
:::

:::定理 Gibbs 不等式
$D(P\Vert Q)\ge0$，等号当且仅当 $P=Q$。
|||证明
在支撑兼容时用 $-\ln t\ge1-t$：$D_e(P\Vert Q)\ge\sum_{P(x)>0}(P(x)-Q(x))\ge0$。等号要求支撑外无质量且每个比值为 1。不兼容时散度为正无穷。
:::

:::定理 熵链式法则与条件化
$H(X,Y)=H(X)+H(Y\mid X)$，$H(X_1,\ldots,X_n)=\sum_iH(X_i\mid X_1,\ldots,X_{i-1})$。$0\le H(X\mid Y)\le H(X)$，$I(X;Y)=H(X)-H(X\mid Y)\ge0$，等号当且仅当独立。
|||证明
把联合概率分解为边缘概率乘条件概率，再展开对数。互信息非负应用 Gibbs 不等式。条件熵非负本身不足以证明互信息非负，必须证明条件熵不超过原熵。
:::

:::定理 最大熵与次可加性
取值不超过 $m$ 个的变量满足 $H(X)\le\log_2m$，等号为均匀分布。$H(X_1,\ldots,X_n)\le\sum_iH(X_i)$，等号在相互独立时成立，有限熵情况下也为必要条件。
|||证明
与均匀分布比较，散度为 $\log_2m-H(X)$。次可加性由链式法则与条件化降低熵逐项得到。
:::

:::定理 散度链式法则与数据处理
$D(P_{XY}\Vert Q_{XY})=D(P_X\Vert Q_X)+E_{P_X}D(P_{Y|X}\Vert Q_{Y|X})$。通过相同随机信道处理两分布不会增加散度。若 $X\to Y\to Z$ 构成 Markov 链，则 $I(X;Z)\le I(X;Y)$。
|||证明思路
散度链式法则直接分解对数。边缘化不增散度由条件项非负得到；对联合分布施加同一信道再边缘化即得一般结论。互信息版本也可用 $I(X;Y,Z)$ 的两种链式展开以及 $I(X;Z\mid Y)=0$ 推出。
:::

:::定理 Pinsker 不等式
总变差 $\|P-Q\|_{\rm TV}=\frac12\sum_x|P(x)-Q(x)|$ 满足 $D_e(P\Vert Q)\ge2\|P-Q\|_{\rm TV}^2$；以比特计则 $D_2\ge(2/\ln2)\|P-Q\|_{\rm TV}^2$。
|||证明思路
取 $A=\{x:P(x)\ge Q(x)\}$，则 $P(A)-Q(A)$ 为总变差。数据处理把分布压成 $1_A$ 的 Bernoulli 分布，再对二元散度用凸性或求导得 $d_e(p\Vert q)\ge2(p-q)^2$。
:::

:::定理 Shearer 型三变量熵不等式
$2H(X,Y,Z)\le H(X,Y)+H(X,Z)+H(Y,Z)$。有限集合 $S\subseteq A\times B\times C$ 的三个二维投影大小为 $n_{AB},n_{AC},n_{BC}$ 时，$|S|^2\le n_{AB}n_{AC}n_{BC}$。
|||证明
三组两变量熵之和减去 $2H(X,Y,Z)$，等于 $I(X;Y)+I(Z;Y\mid X)+I(Z;X\mid Y)$，非负。再取 $S$ 上均匀分布，联合熵为 $\log_2|S|$，各投影熵被其支持集大小的对数上界控制。
:::

互信息的多变量推广有不同约定。条件互信息非负，但三变量交互信息 $I(X;Y)-I(X;Y\mid Z)$ 可以为负，不能机械套用二元互信息结论。
