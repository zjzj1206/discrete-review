# 01 · 集合、关系与无穷

集合论提供全部课程的对象语言。有限计数依赖双射，无穷比较也依赖双射；关系用于把对象分成等价类或排成偏序，商集合则是商群、商环的前身。

## 集合与映射

先把集合、集合的元素、元素之间的关系分开。例如研究班级座位时，“学生集合”是对象范围，“同桌”是两个学生之间的关系，“学号”则把学生映到整数。后面群论中的等价类、概率中的事件、图论中的邻接关系，都在重复使用这些基本结构。

:::例题 从逐元素证明开始：为什么逆像保持交集
对函数 $f:X\to Y$ 及 $A,B\subseteq Y$，证明 $f^{-1}(A\cap B)=f^{-1}(A)\cap f^{-1}(B)$，并说明为什么像集的类似等式会失败。
|||逐步证明与反例
证明两个集合相等，可以固定一个任意元素，连续翻译“属于”的含义：

$$x\in f^{-1}(A\cap B)\iff f(x)\in A\cap B\iff(f(x)\in A\text{ 且 }f(x)\in B)\iff x\in f^{-1}(A)\cap f^{-1}(B).$$

每一个双向箭头都只是定义，没有使用单射或满射假设，所以对任何函数成立。

换成像集，$y\in f(U)\cap f(V)$ 只保证有 $u\in U,v\in V$ 分别映到 $y$，不能保证同一个原像落在 $U\cap V$。取 $f:\{1,2\}\to\{0\}$ 为常值函数，$U=\{1\},V=\{2\}$，左边 $f(U\cap V)=\varnothing$，右边却为 $\{0\}$。若加上单射，$f(u)=f(v)$ 迫使 $u=v$，缺口才被补上。
:::

:::定义 有序对、关系的定义域与逆关系
集合论可把有序对编码为 $(a,b)=\{\{a\},\{a,b\}\}$，它满足 $(a,b)=(c,d)\iff a=c,b=d$。二元关系是笛卡尔积的子集 $R\subseteq X\times Y$；定义域是出现为第一坐标的元素集，值域是出现为第二坐标的元素集。逆关系交换坐标，关系复合把两步连接成一步。
|||解释：函数为什么是一种特殊关系
若 $R$ 是 $X$ 到 $Y$ 的函数，必须对每个 $x\in X$ 恰有一个 $y$ 使 $(x,y)\in R$。“至少一个”是处处有定义，“至多一个”是单值性。逆关系成为 $Y$ 到 $X$ 的函数，恰好要求原函数双射；否则可能出现某个 $y$ 无原像或有多个原像。

例如 $R=\{(1,a),(2,a),(3,b)\}$ 是函数，但其逆关系在 $a$ 上有两个值。关系复合中的存在量词解释了传递性：若 $xRy$ 且 $yRz$，则存在中间点 $y$，传递闭包要把 $(x,z)$ 也加入。
:::

:::例题 等价类怎样变成新的对象
在整数上令 $a\sim b\iff3\mid(a-b)$，写出等价类并解释商集。
|||逐步解释
自反性来自 $3\mid0$；对称性来自整除对取负封闭；传递性来自 $a-c=(a-b)+(b-c)$。三个等价类为 $[0]=3\mathbb Z$、$[1]=1+3\mathbb Z$、$[2]=2+3\mathbb Z$。

商集不是从每一类随便取一个整数后忘掉其他元素，而是把整个等价类当成一个新元素。为了定义 $[a]+[b]=[a+b]$，还要证明代表元选择无关：若 $a-a'$、$b-b'$ 均为 3 的倍数，则 $(a+b)-(a'+b')$ 也是。这一步叫“良定义”，会在商群、商环中再次出现。
:::

:::定义 上下界、上确界与 Hasse 图
偏序集里，$u$ 是 $S$ 的上界指每个 $s\in S$ 满足 $s\le u$；上确界是全体上界中的最小元，记 $\sup S$，下确界对偶定义。有限偏序的 Hasse 图仅画覆盖关系：$x<y$ 且不存在 $x<z<y$ 时连接 $x,y$，省去自反边和由传递性得到的边。
|||解释与例子
以正整数上的整除为偏序，集合 $\{6,10\}$ 的下确界为 2，上确界为 30。这里“最大”“最小”按整除比较，不是按实数大小随意比较。在有理数按通常大小排序时，$\{q:q^2<2,\ q>0\}$ 有有理上界但没有有理上确界；上确界是否存在取决于所处偏序集。
:::

:::定义 集合运算与幂集
$A\subseteq B$ 表示 $A$ 的每个元素属于 $B$；$\mathcal P(A)=\{S:S\subseteq A\}$。差集为 $A\setminus B$，对称差为 $A\triangle B=(A\setminus B)\cup(B\setminus A)$。笛卡尔积 $A\times B$ 由有序对 $(a,b)$ 组成。
|||解释与边界
$\varnothing\subseteq A$ 恒成立，但 $\varnothing\in A$ 未必成立。$\{\varnothing\}$ 有一个元素。判断集合恒等式可逐元素比较，或用特征函数；对称差对应模二加法。
:::

:::定义 函数、单射、满射与双射
函数 $f:A\to B$ 对每个 $a\in A$ 指派唯一 $f(a)\in B$。单射指 $f(a)=f(a')\Rightarrow a=a'$；满射指 $f(A)=B$；双射兼具两者。逆像 $f^{-1}(S)=\{a:f(a)\in S\}$ 对任何函数均有定义，逆函数则要求双射。
|||解释
逆像保持并、交、补（补相对于定义域和陪域），像保持并但一般不保持交。$f(A\cap B)\subseteq f(A)\cap f(B)$，单射时取等。
:::

:::定义 等价关系、偏序、全序与良序
等价关系满足自反、对称、传递；等价类 $[x]=\{y:y\sim x\}$ 组成商集。偏序满足自反、反对称、传递；全序要求任意两点可比；良序要求每个非空子集有最小元。
|||解释
反对称不是“不对称”：$x\le y$ 且 $y\le x$ 蕴含 $x=y$。极大元只排除严格更大的元素；最大元还要大于等于所有元素。有限非空偏序集有极大元，但不一定有最大元。
:::

:::定理 等价关系与划分一一对应
等价关系的等价类互不相交且覆盖原集合。反过来，任意划分通过“落在同一块中”定义等价关系。
|||证明
自反性保证覆盖。若 $[x]\cap[y]$ 含 $z$，由对称性与传递性得 $x\sim y$，再得 $[x]=[y]$。反方向逐条验证三条性质即可。
:::

:::定义 关系闭包
自反闭包加入全部 $(x,x)$；对称闭包加入全部反向边；传递闭包 $R^+=\bigcup_{k\ge1}R^k$，其中关系复合对应沿边走一步。自反传递闭包为 $R^*=I\cup R^+$。
|||解释
有限集合中可用可达性计算传递闭包。对有向图先忽略方向，再取连通分量，得到包含原关系的最小等价关系。
:::

## 基数与对角线

有限集合可以数元素，无限集合不能靠“列表还剩多少”比较。最可靠的办法是构造双射或两个方向的单射。构造完成后，分别核查：每个输入有输出吗、输出落在目标集合吗、是否碰撞、是否漏掉目标。

:::例题 详细枚举：整数、有理数与有限字符串为什么可数
说明 $\mathbb Z$、$\mathbb Q$ 和有限字母表上的全部有限字符串均至多可数。
|||构造与验证
整数可列成 $0,1,-1,2,-2,\ldots$。对正有理数，先枚举正整数对 $(a,b)$：按 $a+b=2,3,4,\ldots$ 分层，每层有限。输出 $a/b$ 并跳过已出现的值，就枚举了全部正有理数；因为任意 $a/b$ 都在有限层中出现。再插入零和负数即可。

有限字符串按长度分层，长度为 $k$ 的字符串只有 $m^k$ 个。按长度再按字典序排列，因此可数。这里必须是“有限长度”；无限 01 序列不能在某个有限层里出现，Cantor 对角线正是证明这些无限序列不可数。

同理可数个可数集的并，可先给各集合编号，再给其元素编号，形成二维表并沿对角线遍历。在 ZFC 中可同时选择这些枚举；在不含选择公理的弱系统中，这一步需要更细的讨论。
:::

:::定义 Dedekind 有限与连续统假设
集合若不与任何真子集等势，称 Dedekind 有限。在 ZFC 中它等价于通常的有限性。连续统假设 CH 断言不存在基数严格介于 $\aleph_0$ 与 $2^{\aleph_0}$ 之间的集合；在选择公理下也写作 $2^{\aleph_0}=\aleph_1$。
|||解释与适用边界
映射 $n\mapsto n+1$ 把 $\mathbb N$ 双射到其真子集，显示无限集合能有“整体与真部分同样大”的现象。若无限集合可良序，依次取最小未选元素即可找出一个可数无限子集，将它整体后移一位，其余元素不动，便构造上述双射。

CH 的独立性意味着：假如 ZFC 一致，ZFC 既不能证明 CH，也不能证明其否定。这不是“CH 既真又假”，而是同一公理体系不能唯一决定它。此处记录元数学结论，其独立性证明需要构造性宇宙与 forcing，超出本课程基础证明工具。
:::

:::定义 基数、可数与不可数
$|A|=|B|$ 表示存在双射；$|A|\le |B|$ 表示存在单射 $A\to B$。有限集与能和 $\mathbb N$ 建立双射的集合统称至多可数；不至多可数的集合称不可数。
|||解释
$\mathbb Z$、$\mathbb Q$ 可数，有限字符串集合可数。可数个可数集之并在通常 ZFC 框架内可数；枚举二维指标可按对角线进行。无限字符串集不等于有限字符串集。
:::

:::定理 Cantor 定理
任意集合 $A$ 满足 $|A|<|\mathcal P(A)|$。
|||证明
$a\mapsto\{a\}$ 给出单射。若存在满射 $f:A\to\mathcal P(A)$，令 $D=\{a\in A:a\notin f(a)\}$。取 $d$ 使 $f(d)=D$，则 $d\in D\iff d\notin D$，矛盾。
:::

:::定理 Cantor–Schröder–Bernstein
若存在单射 $f:A\to B$ 与 $g:B\to A$，则存在双射 $A\to B$。
|||证明
令 $A_0=A\setminus g(B)$，$A_{n+1}=g(f(A_n))$，$C=\bigcup_{n\ge0}A_n$。在 $C$ 上用 $f$，在 $A\setminus C$ 上用 $g^{-1}$。后者有定义。前一部分的像是 $f(C)$，后一部分恰好映到 $B\setminus f(C)$，所以拼接映射为双射。
:::

:::定理 实数不可数
$\{0,1\}^{\mathbb N}$ 不可数，且 $|\mathbb R|=2^{\aleph_0}$。
|||证明思路
对任何声称穷尽二进制序列的列表，第 $n$ 位取与第 $n$ 行第 $n$ 位相反的数，所得序列不在列表中。用三进制仅含 0、2 的展开可将此序列空间单射到实数，避免二进制展开的不唯一问题；反向可用实数的有理下割编码。
:::

:::定义 序数与基数运算
序数是由隶属关系良序的传递集合，$0=\varnothing$、$\alpha+1=\alpha\cup\{\alpha\}$，第一个无限序数为 $\omega$。基数可选为同一等势类中最小的序数。基数加法用不交并、乘法用笛卡尔积、幂用函数集合定义。
|||解释
序数记顺序类型，基数只记大小；$1+\omega=\omega$ 而 $\omega+1>\omega$，序数加法不交换。函数集合满足 $(Z^Y)^X\cong Z^{X\times Y}$，由“柯里化”双射 $f\mapsto((x,y)\mapsto f(x)(y))$ 得到。
:::

:::定理 超限归纳与良序比较
在良序集上，若每个元素的所有前驱满足某性质便能推出该元素也满足，则全体元素满足。任意两个良序集，一个与另一个相同或某个初始段序同构。
|||证明思路
超限归纳若失败，取最小反例便矛盾。比较定理将两个良序集的同构初始段匹配，利用良序消除分歧；匹配的并必须耗尽至少一侧。结合选择公理可得任意集合的基数可比较。
:::

做无穷题时优先寻找编码和双射，而不是套用有限集合直觉。无限真子集可以与原集合等势；“所有有限对象”与“所有无限序列”往往属于不同基数。

## 自然数、序数与选择：区分大小和顺序

自然数先描述有限的后继过程，序数把这个过程推广到任意良序，基数则忽略顺序只比较元素数量。无限情形中，同样大小的集合可以有不同顺序类型，因此序数运算与基数运算不能混用。

:::定义 后继序数、极限序数与序数递归
序数 $\alpha$ 的后继为 $\alpha+1=\alpha\cup\{\alpha\}$；非零且不是后继的序数称极限序数，例如 $\omega$。极限阶段通过前面各阶段的并定义，例如 $\sup_i\alpha_i=\bigcup_i\alpha_i$。
|||序数加乘法的递归方向
加法规定 $\alpha+0=\alpha$、$\alpha+(\beta+1)=(\alpha+\beta)+1$，极限时 $\alpha+\lambda=\sup_{\beta<\lambda}(\alpha+\beta)$。乘法规定 $\alpha\cdot0=0$、$\alpha\cdot(\beta+1)=\alpha\cdot\beta+\alpha$，极限时取前项上确界。

于是 $1+\omega=\sup_n(1+n)=\omega$，但 $\omega+1$ 多出一个位于所有自然数之后的最大点，不能与 $\omega$ 序同构。$2\cdot\omega=\sup_n2n=\omega$，而 $\omega\cdot2=\omega+\omega$ 是两个自然数块前后排列。二者基数都是 $\aleph_0$，顺序类型不同。
:::

:::定理 良序集与唯一序数对应
每个良序集都与唯一序数序同构；两个不同序数不能序同构。
|||把每个点替换成它之前的类型
对良序集 $(X,<)$ 递归定义 $F(x)=\{F(y):y<x\}$。良序保证定义只依赖已经处理的前驱；归纳可证这些值为序数，且 $x<y$ 当且仅当 $F(x)\in F(y)$。全部像的集合是一个传递、被隶属关系良序的集合，所以本身是序数，$F$ 给出所需同构。

唯一性可用“首次分歧”论证：两个序数之间的序同构必须把每个点映到由其前驱像组成的集合；若前驱都固定，该点也固定。超限归纳说明同构处处恒等，所以两个序数相同。严谨构造依赖超限递归定理与替换公理来保证像是集合。
:::

:::定理 自然数上的递归定理
给定集合 $X$、初值 $a\in X$ 与函数 $g:X\to X$，存在唯一 $f:\mathbb N\to X$ 满足 $f(0)=a$、$f(n+1)=g(f(n))$。
|||归纳与递归解决的是不同任务
归纳证明已有对象的性质；递归定理保证按步骤描述的对象确实存在且唯一。对每个 $n$，有限序列 $a,g(a),\ldots,g^n(a)$ 可归纳构造；不同长度的序列在共同部分相容，取并得到总函数。若有两个候选函数，初值相同且每一步由前一步唯一决定，归纳即得逐点相等。

自然数加法可令初值为固定的 $m$、每步取后继，定义 $m+0=m,m+(n+1)=(m+n)+1$；乘法再递归为 $m\cdot0=0,m\cdot(n+1)=m\cdot n+m$。交换律不是定义直接给出的，须另行归纳证明。
:::

:::定义 选择公理、良序定理与 Zorn 引理
选择公理要求任意一族非空集合有选择函数；良序定理说每个集合都能良序；Zorn 引理说，非空偏序集若每条链在其中都有上界，则有极大元。在 ZF 中这三个命题等价。
|||Zorn 的使用模板与向量空间基
为寻找向量空间的基，取全部线性无关子集，按包含排序。空集提供非空性。一条包含链的并仍线性无关：任何有限线性关系只涉及有限个向量，它们都落入链中某一项，故系数为零。因此链并就是上界。

Zorn 给极大线性无关集 $B$。若它不张成空间，可取张成之外的 $v$，则 $B\cup\{v\}$ 仍无关，与极大性矛盾，所以 $B$ 是基。这里极大指不能扩张，不是说它包含其他所有无关集；各条链有上界也不等于整个偏序有最大元。

三者等价的全部证明需要较长超限构造，这里给出准确陈述与 Zorn 的完整应用，未把应用当成等价性的证明。
:::
