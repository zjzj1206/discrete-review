# 02 · 命题逻辑与证明系统

逻辑有两条平行路线：语义问“所有赋值中是否为真”，语法问“能否按规则推出”。可靠性连接语法到语义，完备性连接语义到语法。

## 语义与自然演绎

:::定义 公式、赋值与逻辑后承
命题公式由命题变元、$\bot$ 与连接词递归构成。$v(\varphi\to\psi)=0$ 当且仅当前件真、后件假。$\Gamma\models\varphi$ 表示每个满足 $\Gamma$ 的赋值都满足 $\varphi$；$\models\varphi$ 表示永真；$\Gamma\vdash\varphi$ 表示存在形式推导。
|||解释
可满足是“存在一个模型”，有效是“每个模型都成立”，二者不能交换。蕴含式 $\varphi\to\psi$ 是语言里的公式，$\varphi\models\psi$ 是关于公式的元语言陈述。
:::

:::定义 自然演绎规则
合取引入由 $\varphi,\psi$ 得 $\varphi\land\psi$，消去可取任一分量。蕴含消去由 $\varphi,\varphi\to\psi$ 得 $\psi$；蕴含引入在临时假设 $\varphi$ 下导出 $\psi$ 后撤销假设。析取引入可加入另一分支，析取消去要求两个分支导出同一结论。$\bot$ 消去允许从矛盾推出任意式。令 $\neg\varphi$ 缩写 $\varphi\to\bot$。
|||解释
证明必须跟踪尚未撤销的假设。析取消去中不能只证明一个分支；蕴含引入不是删除一切假设，而是撤销指定临时假设。
:::

:::定义 RAA、经典逻辑与直觉主义逻辑
RAA 规则是在假设 $\neg\varphi$ 下导出 $\bot$，进而撤销该假设并得出 $\varphi$。保留标准自然演绎而不使用 RAA 得到直觉主义系统；加入 RAA 得到经典系统。
|||解释
从 $\varphi$ 假设导出矛盾并得 $\neg\varphi$ 是否定引入，本身不需要 RAA。经典系统允许双重否定消去和排中律；直觉主义一般不允许。
:::

:::定理 可靠性与完备性
经典命题自然演绎满足 $\Gamma\vdash\varphi\iff\Gamma\models\varphi$。
|||证明思路
可靠性对推导树归纳，逐条检查规则保真。有限前提的完备性可按真值表逐赋值构造证明，再用排中律合并情形；一般前提使用紧致性或极大一致集构造。不要把“某一种语义不完备”误解成该系统对一切语义不完备。
:::

:::定理 演绎定理与紧致性
自然演绎中 $\Gamma,\varphi\vdash\psi\iff\Gamma\vdash\varphi\to\psi$。命题集合可满足，当且仅当它的每个有限子集可满足。
|||证明
前一结论分别由蕴含引入与消去得到。紧致性可由完备性与“证明只使用有限个前提”推出：若整体不可满足，能推出 $\bot$，该证明只用有限前提，因而某有限子集已不可满足。
:::

## 直觉主义与序列演算

:::定义 Kripke 模型
模型由偏序世界集 $(W,\le)$ 与向上保持的原子真值组成。$w\Vdash\varphi\to\psi$ 当且仅当每个 $v\ge w$ 中，$v\Vdash\varphi$ 蕴含 $v\Vdash\psi$；没有世界强迫 $\bot$。合取、析取按相应局部规则解释。
|||解释与反例
取 $w_0<w_1$，$p$ 只在 $w_1$ 成立。则 $w_0$ 不强迫 $p$，也不强迫 $\neg p$，所以不强迫排中律。否定要求所有未来世界都无法使被否定公式成立。
:::

:::引理 强迫关系的单调性
若 $w\Vdash\varphi$ 且 $v\ge w$，则 $v\Vdash\varphi$。
|||证明
对公式结构归纳。原子情形是模型条件；合取、析取直接继承。蕴含情形中，$v$ 的未来世界也是 $w$ 的未来世界，故条件仍成立。
:::

:::定义 序列与 System K 的阅读方式
多后件序列 $\Gamma\Rightarrow\Delta$ 表达：若左侧全部为真，则右侧至少一个为真。空后件表示矛盾。课程里的 System K 按所引用序列演算教材理解，不应和模态逻辑中的同名系统混淆。
|||解释
典型蕴含右规则将 $\Gamma,\varphi\Rightarrow\Delta,\psi$ 变成 $\Gamma\Rightarrow\Delta,\varphi\to\psi$。结构规则处理交换、弱化和收缩；具体可用规则以原题给出的系统为准。
:::

:::例题 Peirce 律的经典证明
证明 $((p\to q)\to p)\to p$。
|||证明
假设 $H:(p\to q)\to p$。再假设 $\neg p$，临时假设 $p$ 即得矛盾，由爆炸律得 $q$，撤销 $p$ 得 $p\to q$。与 $H$ 得 $p$，再次矛盾。用 RAA 撤销 $\neg p$ 得 $p$，最后撤销 $H$。关键的经典步骤正是 RAA。
:::

检查证明时先标出假设作用域，再检查每次消去规则的输入。要否证“可推导”，应寻找适用于该系统的反模型，而不是只说真值表没有帮助。
