# 02 · 命题逻辑与证明系统

逻辑有两条平行路线：语义问“所有赋值中是否为真”，语法问“能否按规则推出”。可靠性连接语法到语义，完备性连接语义到语法。

## 语义与自然演绎

可以把公式看成“表达式”，赋值看成“给输入赋真值”，推导看成“遵守规则的程序”。学习时先能手算一个公式的真值，再练习从假设逐步推出结论，最后才讨论为什么整个证明系统不会漏掉语义上正确的推理。

:::定义 公式的递归构造与结构归纳
给定命题变元集 $P$，先把 $P$ 中每个变元及 $\bot$ 视为公式；已有公式 $\varphi,\psi$ 后可构造 $\varphi\land\psi$、$\varphi\lor\psi$、$\varphi\to\psi$，不由有限次构造得到的字符串不算公式。语法树的根是最后使用的连接词，叶子是原子。
|||解释：证明关于所有公式的性质
证明“每个公式都具有性质 $Q$”，要先证明原子具有 $Q$，再证明各构造保留 $Q$。例如每个公式只含有限多个变量：原子只含零或一个；二元连接词将两个有限变量集合取并，仍有限。

括号规定作用域。$p\to(q\to r)$ 的根为外层蕴含，而 $(p\to q)\to r$ 的左子树已经是一个蕴含，二者不等价。所谓生成序列，是将语法树的节点排成“子式先于父式”的构造顺序。
:::

:::例题 真值表、等价变形与范式
判断 $(p\to q)\leftrightarrow(\neg q\to\neg p)$，并说明如何从真值表构造析取范式 DNF 和合取范式 CNF。
|||逐步解释
$p\to q$ 只在 $p=1,q=0$ 时假；$\neg q\to\neg p$ 也恰在同一行假，故两式在经典语义下等价。这也可由 $p\to q\equiv\neg p\lor q$ 直接看出。

构造 DNF：为每个真值为 1 的输入行写一个合取项，该行变量为 1 就写变量、为 0 就写否定，再把这些项析取。例如异或真值行是 $(1,0),(0,1)$，得到 $(p\land\neg q)\lor(\neg p\land q)$。

构造 CNF：为每个假值行写一个恰在该行假的析取子句，再把子句合取。异或在 $(0,0)$ 和 $(1,1)$ 假，得到 $(p\lor q)\land(\neg p\lor\neg q)$。这些是经典等价表达，不自动给出指定自然演绎系统里的推导步骤。
:::

:::例题 一份逐行自然演绎证明
不用 RAA，证明 $(p\to q)\to(\neg q\to\neg p)$。
|||每一步与假设作用域
1. 假设 $h:p\to q$，目标变为 $\neg q\to\neg p$。
2. 假设 $k:\neg q$，目标变为 $\neg p$，也就是 $p\to\bot$。
3. 假设 $a:p$。当前未撤销的假设为 $h,k,a$。
4. 由 $h$ 和 $a$ 使用 $\to E$ 得 $q$。
5. 将 $k$ 看成 $q\to\bot$，与上一步用 $\to E$ 得 $\bot$。
6. 撤销假设 $a$，用 $\to I$ 得 $p\to\bot$，即 $\neg p$。
7. 撤销 $k$，得 $\neg q\to\neg p$。
8. 撤销 $h$，得到目标公式。

这里“从假设 $p$ 导出矛盾得到 $\neg p$”是蕴含引入，不是经典反证 RAA；因此该式在直觉主义中也可证。
:::

:::引理 真值赋值对应的文字集引理
对公式 $\varphi$ 中的每个变量，按赋值 $v$ 把真变量本身、假变量的否定放进 $\Gamma_v$。经典自然演绎中，若 $v(\varphi)=1$ 则 $\Gamma_v\vdash\varphi$；若 $v(\varphi)=0$ 则 $\Gamma_v\vdash\neg\varphi$。
|||结构归纳证明的关键步骤
原子情形直接取假设；$\bot$ 的否定由假设 $\bot$ 推出自身再撤销可得。合取真时，两部分都真，归纳假设给出两部分再合取；合取假时，至少一部分假，假设整个合取就能取出该部分并制造矛盾。

蕴含真分两种情况：后件真，则假设前件后直接用归纳所得后件；前件假，则假设前件制造矛盾，再爆炸推出后件。蕴含假时前件真、后件假，假设该蕴含便能推出后件而矛盾。析取的情形通过引入、分情况消去同样完成。

若 $\varphi$ 是永真式，对全部有限种赋值都得到证明。然后用 $p\lor\neg p$ 分情况消去每个变量假设，最终得到无假设证明。这里就是有限变量命题完备性的实际构造；经典性体现在排中律合并各分支。
:::

:::定义 公式、赋值与逻辑后承
命题公式由命题变元、$\bot$ 与连接词递归构成。$v(\varphi\to\psi)=0$ 当且仅当前件真、后件假。$\Gamma\models\varphi$ 表示每个满足 $\Gamma$ 的赋值都满足 $\varphi$；$\models\varphi$ 表示永真；$\Gamma\vdash\varphi$ 表示存在形式推导。
|||解释
可满足是“存在一个模型”，有效是“每个模型都成立”，二者不能交换。蕴含式 $\varphi\to\psi$ 是语言里的公式，$\varphi\models\psi$ 是关于公式的元语言陈述。
:::

:::定义 自然演绎规则
合取引入由 $\varphi,\psi$ 得 $\varphi\land\psi$，消去可取任一分量。蕴含消去由 $\varphi,\varphi\to\psi$ 得 $\psi$；蕴含引入在临时假设 $\varphi$ 下导出 $\psi$ 后撤销假设。析取引入可加入另一分支，析取消去要求两个分支导出同一结论。$\bot$ 消去允许从矛盾推出任意式。令 $\neg\varphi$ 缩写 $\varphi\to\bot$。
|||解释
证明必须跟踪尚未撤销的假设。析取消去中不能只证明一个分支；蕴含引入不是删除一切假设，而是撤销指定临时假设。
:::

:::定义 RAA、经典逻辑与直觉主义逻辑
RAA 规则是在假设 $\neg\varphi$ 下导出 $\bot$，进而撤销该假设并得出 $\varphi$。保留标准自然演绎而不使用 RAA 得到直觉主义系统；加入 RAA 得到经典系统。
|||解释
从 $\varphi$ 假设导出矛盾并得 $\neg\varphi$ 是否定引入，本身不需要 RAA。经典系统允许双重否定消去和排中律；直觉主义一般不允许。
:::

:::定理 可靠性与完备性
经典命题自然演绎满足 $\Gamma\vdash\varphi\iff\Gamma\models\varphi$。
|||证明思路
可靠性对推导树归纳，逐条检查规则保真。有限前提的完备性可按真值表逐赋值构造证明，再用排中律合并情形；一般前提使用紧致性或极大一致集构造。不要把“某一种语义不完备”误解成该系统对一切语义不完备。
:::

:::定理 演绎定理与紧致性
自然演绎中 $\Gamma,\varphi\vdash\psi\iff\Gamma\vdash\varphi\to\psi$。命题集合可满足，当且仅当它的每个有限子集可满足。
|||证明
前一结论分别由蕴含引入与消去得到。紧致性可由完备性与“证明只使用有限个前提”推出：若整体不可满足，能推出 $\bot$，该证明只用有限前提，因而某有限子集已不可满足。
:::

## 直觉主义与序列演算

:::例题 两个世界怎样否证 Peirce 律的直觉主义可证性
取链 $w_0<w_1$，令 $p$ 只在 $w_1$ 成立，$q$ 在两个世界都不成立。检查 $((p\to q)\to p)\to p$ 在 $w_0$ 不被强迫。
|||逐层计算
首先在 $w_1$，$p$ 真、$q$ 假，所以 $p\to q$ 不成立。在 $w_0$，未来世界 $w_1$ 已经给出反例，所以 $p\to q$ 也不成立。

因此，从 $w_0$ 开始的所有世界都没有满足 $p\to q$ 的世界，故条件“凡满足 $p\to q$ 都满足 $p$”为空真：$w_0\Vdash(p\to q)\to p$。但 $w_0\not\Vdash p$，所以在 $w_0$ 本身就能反驳最外层蕴含。

直觉主义推导的每条规则对 Kripke 模型可靠，故若该式可推导，就应在此模型成立；矛盾。注意这里不是简单地把 $w_0$ 的“尚未知道 $p$”当成“知道 $\neg p$”，后者要求所有未来都不出现 $p$。
:::

:::定义 Frege／Hilbert 风格证明与序列演算的差别
Hilbert 风格从公理模式的实例开始，典型推理规则为 Modus Ponens：由 $A$ 和 $A\to B$ 得 $B$。一套常见经典蕴含—否定公理模式为 $A\to(B\to A)$、$(A\to(B\to C))\to((A\to B)\to(A\to C))$、$(\neg B\to\neg A)\to(A\to B)$。不同教材可选用等价的其他模式。
|||解释与一个形式推导
推导 $A\to A$：先由第一模式得 $A\to((A\to A)\to A)$ 与 $A\to(A\to A)$；第二模式代入 $B=A\to A,C=A$ 后得 $[A\to((A\to A)\to A)]\to([A\to(A\to A)]\to(A\to A))$。两次 Modus Ponens 即得结论。

自然演绎把“暂时假设再撤销”作为规则，Hilbert 系统把相同能力编码进公理模式；序列演算则将左右环境一起记录，每个连接词有左右引入规则。题目指定哪一种系统，就必须用那一种系统作证，不能只给真值表代替。
:::

:::定义 Kripke 模型
模型由偏序世界集 $(W,\le)$ 与向上保持的原子真值组成。$w\Vdash\varphi\to\psi$ 当且仅当每个 $v\ge w$ 中，$v\Vdash\varphi$ 蕴含 $v\Vdash\psi$；没有世界强迫 $\bot$。合取、析取按相应局部规则解释。
|||解释与反例
取 $w_0<w_1$，$p$ 只在 $w_1$ 成立。则 $w_0$ 不强迫 $p$，也不强迫 $\neg p$，所以不强迫排中律。否定要求所有未来世界都无法使被否定公式成立。
:::

:::引理 强迫关系的单调性
若 $w\Vdash\varphi$ 且 $v\ge w$，则 $v\Vdash\varphi$。
|||证明
对公式结构归纳。原子情形是模型条件；合取、析取直接继承。蕴含情形中，$v$ 的未来世界也是 $w$ 的未来世界，故条件仍成立。
:::

:::定义 序列与 System K 的阅读方式
多后件序列 $\Gamma\Rightarrow\Delta$ 表达：若左侧全部为真，则右侧至少一个为真。空后件表示矛盾。课程里的 System K 按所引用序列演算教材理解，不应和模态逻辑中的同名系统混淆。
|||解释
典型蕴含右规则将 $\Gamma,\varphi\Rightarrow\Delta,\psi$ 变成 $\Gamma\Rightarrow\Delta,\varphi\to\psi$。结构规则处理交换、弱化和收缩；具体可用规则以原题给出的系统为准。
:::

:::例题 Peirce 律的经典证明
证明 $((p\to q)\to p)\to p$。
|||证明
假设 $H:(p\to q)\to p$。再假设 $\neg p$，临时假设 $p$ 即得矛盾，由爆炸律得 $q$，撤销 $p$ 得 $p\to q$。与 $H$ 得 $p$，再次矛盾。用 RAA 撤销 $\neg p$ 得 $p$，最后撤销 $H$。关键的经典步骤正是 RAA。
:::

检查证明时先标出假设作用域，再检查每次消去规则的输入。要否证“可推导”，应寻找适用于该系统的反模型，而不是只说真值表没有帮助。
